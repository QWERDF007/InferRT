架构审查和演进计划见根目录 [`sol_anylysis.md`](../sol_anylysis.md) 与 [`sol_plan.md`](../sol_plan.md)；本文档只维护结构索引与单一事实来源。

## 2. Engine 异步多设备调度与生命周期架构

```mermaid
sequenceDiagram
    participant User as 调用方 / Client
    participant Engine as InferenceEngine
    participant Scheduler as EngineScheduler
    participant Prepare as CPU Prepare Workers
    participant Executor as SlotExecutor
    participant Slot as ExecutionSlot (Device i)
    participant Postprocess as CPU Postprocess Workers
    participant Order as CompletionOrder
    participant Tickets as TicketPool
    participant Promise as Request Promise

    User->>Engine: submit(image, options)
    Engine->>Scheduler: register and admit request

    loop 调度循环 (Scheduler Loop)
        Scheduler->>Scheduler: 形成动态 Batch (BatchState)
        Scheduler->>Prepare: prepare_queue.push(batch)
        Prepare->>Tickets: acquire input ticket
        Prepare->>Executor: gpu_queue.push(prepared batch)
    end

    Executor->>Tickets: acquire output ticket
    Executor->>Slot: H2D + CUDA preprocess
    Executor->>Slot: RuntimePlan::enqueue (TensorRT / Backend)
    Executor->>Slot: D2H + record completion events

    loop 轮询与后处理 (Completion Loop)
        Executor->>Slot: cudaEventQuery(d2h_done)
        alt 事件完成 (Ready)
            Executor->>Postprocess: postprocess_queue.push(batch)
            Postprocess->>Order: complete success/failure
            Order->>Promise: set_value/set_exception [Exactly-Once]
            Postprocess->>Tickets: release output ticket
            Executor->>Tickets: release input ticket
            User-->>User: future.get() 获取推理结果
        end
    end
```

## 3. 模型生命周期与强异常安全事务图

```mermaid
flowchart TD
    A["model->load(new_file) / setModelConfig(new_config)"] --> B["创建临时 RuntimePlan / Backend 对象"]
    B --> C{"新运行时加载与校验是否成功？"}
    C -- 成功 --> D["原子提交新 Runtime 到 active_runtime_"]
    D --> E["更新当前模型配置与有效性状态"]
    C -- 失败抛出异常 --> F["析构临时对象，回滚资源"]
    F --> G["保持旧 active_runtime_ 与旧配置完全无损"]
    G --> H["模型保持 isValid() 且可继续执行推理"]
```

## 4. 统一张量契约与单一真相源 (SSOT)

```mermaid
classDiagram
    class Shape {
        -vector~int64_t~ dims_
        +rank() size_t
        +elementCount() size_t [Checked Overflow]
        +operator[](index) int64_t
    }

    class TensorDesc {
        -Shape shape_
        -TensorDataType dtype_
        -TensorLayout layout_
        -MemoryKind memory_kind_
        +byteSize() size_t [Checked Overflow]
        +elementCount() size_t
    }

    class BufferView {
        -void* data_
        -TensorDesc desc_
        -size_t capacity_bytes_
        +data() void*
        +dataForRequest(index) void* [Checked Range & Overflow]
        +byteSize() size_t
    }

    class PreprocessSpec {
        +int target_width
        +int target_height
        +ColorFormat color_format
        +NormalizePolicy normalize
        +vector~float~ mean
        +vector~float~ stddev
        +bool letterbox
        +validate() void
    }

    class PreprocessGeometry {
        +int resized_width
        +int resized_height
        +int pad_left
        +int pad_top
        +int crop_left
        +int crop_top
        +float scale
    }

    class IExecutionDescriptor {
        +inputs() vector~TensorInfo~
        +outputs() vector~TensorInfo~
    }

    class IExecutableModel {
        +setInputShape(name, shape) void
        +execute(buffers, options) void
    }

    class IExecutionPlan {
        +createSession() unique_ptr~ITensorRuntimeSession~
        +executeSession(session, buffers, options) void
    }

    class IBackendRuntime {
        +load(file, config, name) void
        +ioTensorNames(mode) vector~string~
        +tensorShape(name) Shape
    }

    TensorDesc *-- Shape
    BufferView *-- TensorDesc
    PreprocessSpec --> PreprocessGeometry : resolve
    IExecutableModel --|> IExecutionDescriptor
    IBackendRuntime --|> IExecutableModel
    IBackendRuntime --|> IExecutionPlan
```

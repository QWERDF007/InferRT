## 4. 模型工厂与注册机制图

```mermaid
flowchart TD
    User["调用方"]
    Factory["CreateModel(name, config)"]
    Normalize["名称转小写归一化"]
    Registry["全局模型注册表"]
    Registrar[ModelRegistrar]
    Impl["具体 IModelImpl 子类"]
    Wrapper["IModel 包装对象"]

    User --> Factory
    Factory --> Normalize
    Normalize --> Registry
    Registrar --> Registry
    Registry --> Impl
    Impl --> Wrapper
    Wrapper --> User
```

说明：

- 注册发生在各模型实现编译单元中
- 创建时统一返回 `IModel`
- 调用方不需要直接感知内部实现类

## 6. 分类模型推理流程图

```mermaid
sequenceDiagram
    participant U as 用户
    participant S as classification sample
    participant F as ModelFactory
    participant M as IModel
    participant I as IModelImpl
    participant TRT as TensorRT
    participant GPU as CUDA

    U->>S: 传入 model_name / weights / image
    S->>F: CreateModel(model_name)
    F-->>S: IModel
    S->>M: buildOrLoad(weights_file)
    M->>I: buildOrLoad(weights_file)
    alt 已存在 engine
        I->>TRT: load(engine)
    else 不存在 engine
        I->>TRT: build(network/engine)
        I->>TRT: save(engine)
    end
    S->>GPU: 图像预处理与缓冲准备
    S->>M: infer(buffers)
    M->>I: infer(buffers)
    I->>TRT: set tensor addresses
    I->>TRT: enqueue/execute
    TRT->>GPU: 执行推理
    GPU-->>S: 输出 logits
    S-->>U: 输出分类结果
```

## 12. 一句话总结

InferRT 当前的最佳理解方式不是“几个样例程序”，而是“一个以 TensorRT 模型封装为中心、以 CUDA 图像算子为扩展方向、同时具备测试和基准支撑的推理基础库骨架”。

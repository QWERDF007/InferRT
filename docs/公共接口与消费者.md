# InferRT 公共接口与消费者

本文档是公共接口变更的审查入口。接口定义以源码和安装导出为准；本文只记录外部合同、消费者索引与迁移决策。

## 安装合同

- CMake 包入口：[`cmake/InferRTConfig.cmake.in`](../cmake/InferRTConfig.cmake.in)
- 导出规则：[`cmake/ConfigCMakePackage.cmake`](../cmake/ConfigCMakePackage.cmake) 与 [`cmake/AddPluginLibrary.cmake`](../cmake/AddPluginLibrary.cmake)
- 已安装目标：`InferRT::core`、`InferRT::util`、`InferRT::ops`、`InferRT::cvcuda`、`InferRT::model`、`InferRT::engine`、`InferRT::features`
- 组件加载：无组件的 `find_package(InferRT CONFIG REQUIRED)` 默认只加载 `InferRT::core`；高级模块通过 `COMPONENTS` 请求；model/engine/features 内部封装 TensorRT、Faiss、ONNX Runtime 与 OpenVINO 等推理后端为私有实现，组件仅向调用方传递公共接口所需的 CUDA 与 OpenCV 依赖
- 公共头：安装树 `include/inferrt/<component>`；精确清单由 Release 安装产物派生，不在文档中复制
- Python 模块：`inferrt_model_py`、`inferrt_ops_py`；构建与安装入口见 [`src/python/CMakeLists.txt`](../src/python/CMakeLists.txt)
- 图后端：ONNX Runtime 与 OpenVINO 为可选构建能力；后端验收以 [`tests/python/test_backend_runtime.py`](../tests/python/test_backend_runtime.py) 的可行性验证为准，实际启用后才按 [`tools/dependencies.yaml`](../tools/dependencies.yaml) 纳入运行库部署集合。

## 入口决策

| 入口 | 合同判定 | 决策 |
| --- | --- | --- |
| `InferenceEngine(EngineConfig, PipelinePlan)` / `create(EngineConfig, PipelinePlan)` | 唯一 Engine 构造入口；Pipeline 必须由调用方显式编译 | 已完成迁移；单参数 legacy 入口已删除，测试专用 legacy pipeline 仅位于 `src/engine/priv/EngineTestHooks.hpp` |
| YOLO、ViT、DINO、RF-DETR、SAM 模型别名 | 权重与模型选择合同 | 保留经过真实模型门禁覆盖的别名；无资源/无消费者证据的别名按模型族整体审查 |
| shape matcher 具体 ISA/版本类 | 不属于安装包公共接口；内部 parity/benchmark 可固定实现 | 消费者只使用 `IShapeTemplateMatcher` 与 `createShapeTemplateMatcher()`；具体实现由 features 内部按 CPU 能力选择 |

删除或重命名公共入口前，必须同时更新本页决策、packaging consumer、对应真实资源测试和安装 relocation 门禁；仓库内无调用者不能单独作为删除依据。

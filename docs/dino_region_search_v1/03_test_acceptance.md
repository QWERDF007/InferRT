# DINO 区域搜图：质量与功能验收

验收目标是确认真实搜索质量与可用错误语义；不设 SHA、manifest、generation、资源预算或发布门禁。

## 功能必测
- `build` 处理真实 JPEG/PNG，并生成可被 `search` 读取的本地索引。
- `search` 支持矩形和多边形 ROI，返回原图坐标、相似度和状态。
- 区域/局部双路粗选、多尺度视图、候选去重与多尺度精匹配均实际执行；边界、空候选、多区域和 `include_self` 行为正确。
- 非法 ROI、缺失/不可解码图片、缺失索引返回明确 `error`，不得伪装为空结果；截止时间到达返回 `incomplete`。

## 真实质量验证（验收必需）
使用与运行目标相符的真实图库、真实正例标注和困难负例，避免查询图泄漏到图库或明确记录其处理方式。至少按场景报告样本数量、矩形/多边形比例、尺度/边界/遮挡/重复纹理覆盖、Top-K 和阈值。计算并报告：

- 正例区域召回率（在规定 Top-K 内找到标注区域）；
- precision（返回区域中满足正例判定的比例）；
- 定位 IoU（预测 bbox 与标注区域的交并比，说明 IoU 判定阈值及聚合方式）。

报告失败案例和未覆盖场景；若数据或硬件不足，明确标注为未完成，不能以示例 YAML 或主观印象代替结果。多尺度、局部通道和精匹配的质量对比应保留可复现实验记录。

## Smoke check（非验收替代）
可用 3～10 张真实图片、至少 3 个 ROI 快速检查 CLI、坐标范围和 Top-K 形状，但该手测只能发现明显回归，不能替代上述真实正例/困难负例质量验证。

## 不测
不要求 HTTP、跨平台发布、固定 SLA、SHA-256、hash、manifest、generation、资源预算门禁或发布锁。性能只记录实际观察值，不设发布阈值。

# 原理图

[principle.png](principle.png) 是 16:9 的通俗原理示意，使用内置 imagegen 生成并校正文字及不透明背景。最终采用第二版；没有添加准确率、速度或压缩率指标。

图中金属圆环与缺口只是解释用的合成示例，不是用户数据，也不是模型真实匹配结果。连线表示局部对应的概念，不是实测对应点。

上半部分：图库多尺度切片 → DINO 特征 → 整体区域描述和局部代表描述 → 紧凑索引。下半部分：框选查询 → 整体/局部双路粗选 → 合并候选 → 候选重算精匹配 → 返回原图框。

其中“相近特征合并”适用于局部代表描述；整体区域描述来自池化。差异局部能否被保留，依赖 DINO 是否表达出差异和合并阈值，图片不表示无损保证。

完整生成与编辑提示见 [generation_prompt.txt](generation_prompt.txt)。算法与坐标约定见[轻量规格](../02_spec.md)，CLI 用法见[示例 README](../examples/README.md)；图片展示矩形查询，多边形查询同样属于文档契约。

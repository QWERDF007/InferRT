# T03 · 区域与局部描述索引

目标：写入可复用的区域/局部描述、坐标和视图元数据。

源码落点：`DinoDescriptors.*`, `DinoIngest.*`, `DinoIndexStore.*`, `DinoStorageFormat.*`。

实施：从 T02 patch token 生成区域描述和局部描述，merge/量化遵循现有 profile；向量用紧凑二进制，元数据用 YAML 约定的内部记录。保存源图路径、视图映射、bbox/多边形覆盖信息。复用现有索引文件，不引入 SHA、manifest、generation 或 JSON 双轨。

验收：建库后能还原描述及原图坐标；配置变化按文档删除索引重建；检查真实正例与困难负例所需数据完整性。

依赖：T02。非范围：增量事务与发布体系。

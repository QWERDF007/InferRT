# T06 · build/search CLI 贯通

目标：贯通真实本地 `build` 与 `search`，输出统一 YAML。

源码落点：`DinoEngine.*`, `DinoRegionSearch.cpp`, `samples/features/dino_region_search/SampleDinoRegionSearch.cpp`。

实施：接入 T01–T05；build 写本地索引，search 读取索引并返回 `status`, `decision`, `results[].source_path/bbox/score`。错误、include_self 和 deadline 语义保持一致，向量仍为二进制。复用现有参数入口，不添加 JSON、manifest 或发布门禁。

验收：用真实 JPEG/PNG 运行 build→search，矩形/多边形均返回可逆原图坐标；缺失输入/索引明确 error，截止时间返回 incomplete。记录命令与实际输出。

依赖：T05。非范围：HTTP、数据库、跨平台发布。

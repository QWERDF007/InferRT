# T01 · 输入坐标与 YAML 契约

目标：冻结 `bbox`/`polygon`、原图像素半开区间、错误和响应状态。

源码落点：`DinoContracts.*`, `DinoGeometry.*`, `DinoQuery.*`, `DinoTypes.*`。

实施：复用现有类型与 yaml-cpp；校验二选一 ROI、边界、空/非有限坐标、`top_k`、`include_self`、`deadline_ms`，并保留多边形几何。定义 `completed/incomplete/error` 与 `ranked_only/incomplete/error` 序列化。禁止新增 JSON/schema 或摘要校验。

验收：矩形和多边形真实请求解析一致；非法输入在模型调用前返回明确 error；坐标转换可回到原图。提交代码路径、命令输出和未完成事项。

依赖：无。非范围：SHA、manifest、发布门禁。

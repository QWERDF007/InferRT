# T05 · 多尺度候选精匹配

目标：只对粗选候选执行多尺度精匹配，恢复准确原图框。

源码落点：`DinoFineMatch.*`, `DinoGeometry.*`, `DinoFusion.*`。

实施：复用候选扩边、模板尺度、局部匹配和边界处理；输出匹配分数、source_path 与 canonical bbox，支持多边形查询和同图多区域。执行排序与 NMS，不以插值伪造原图细节。

验收：真实标注上报告 precision 与 IoU（阈值、聚合方式明确），并保留尺度、遮挡、边界和困难负例失败案例；大窗口不能因未归一化求和天然高分。

依赖：T04。非范围：网络训练和产品化 API。

# T02 · DINOv3 骨干与多尺度视图

目标：一次 backbone 提取覆盖全图和多尺度切片，保证尺度与边界召回。

源码落点：`DinoBackbone.*`, `DinoViews.*`, `DinoFeatureCache.*`。

实施：复用 DINOv3 推理和现有视图/坐标变换；实现全图、切片、重叠率配置，记录每视图到原图映射，避免每窗口重复 forward。保留矩形与多边形 ROI 可用的 patch 覆盖。

验收：真实尺度变化和边界样本可生成完整视图/token 坐标；记录 forward 数和失败样例，不以 3 张图手测代替质量验证。

依赖：T01。非范围：训练、HTTP、资源发布门禁。

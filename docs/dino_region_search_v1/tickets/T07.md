# T07 · 真实质量验证

目标：用真实正例与困难负例证明召回和定位质量，而非仅做手测。

源码落点：`tests/features/TestDinoRegionSearch.cpp`（复用现有测试入口），运行路径为 `SampleDinoRegionSearch.cpp`。

实施：建立不泄漏的真实图库/查询划分，覆盖矩形与多边形、尺度变化、边界、遮挡、重复纹理、多区域和空候选。按预先说明的 Top-K/阈值计算区域召回率、precision、定位 IoU，记录样本数量、聚合方式和失败案例；3–10 张手测仅 smoke check。

验收：交付可复现实验命令、原始结果和未覆盖/未完成事项；不得以示例 YAML、主观判断或发布门禁替代真实质量证据。

依赖：T06。非范围：SHA、manifest、generation、固定 SLA、发布锁。
